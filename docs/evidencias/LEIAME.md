# Evidências

Gere com o serviço no ar (aguarde >= 10 s antes):

    bash scripts/evidencias.sh

Depois adicione capturas de tela legíveis em `capturas/` (navegador em http://localhost:8080,
`docker ps`, `docker exec sdl-servico id`, `docker inspect` antes/depois da falha).
Acrescente 1–2 linhas de explicação para cada evidência.
